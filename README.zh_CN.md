## 快捷键

| 快捷键 | 功能 |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>O</kbd> | 显示或隐藏设置 |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>P</kbd> | 播放或暂停视频 |
